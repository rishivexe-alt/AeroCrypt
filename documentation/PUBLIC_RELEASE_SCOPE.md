# Public Release Scope

This repository is intentionally limited to public-safe AeroCrypt material.

## Included

- secure UAV telemetry architecture
- public-safe ESP32 ground receiver
- public-safe transmitter baseline/reference
- dashboard dependency specification
- hardware documentation
- architecture diagram
- project report
- screenshots
- experimental observations
- security guidance

## Excluded

- real cryptographic keys
- Wi-Fi credentials
- private IPs
- MQTT credentials
- private keys
- personal names/emails/usernames
- private device names
- private development paths
- unverified/fabricated implementation claims

## Project Separation

Industrial IoT/MQTT/gas/distance/SQLite material from the separate prototype is not included in AeroCrypt.
