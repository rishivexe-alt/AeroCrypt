# AeroCrypt Dashboard

The demonstrated AeroCrypt monitoring application is a Python/Streamlit serial-fed visualization layer.

## Documented features

- Receiver status
- LoRa link status
- AES-128-GCM verification status
- Latest packet
- Temperature and pressure
- Accelerometer X/Y/Z
- Gyroscope X/Y/Z
- GPS status
- RSSI/SNR
- Packet history
- CSV export

The original 1364-line dashboard source was audited during development, but its raw source file was not available among the source artifacts used to assemble this public ZIP. Therefore this directory intentionally does not contain a fabricated replacement.

Install documented dependencies with:

```bash
pip install -r requirements.txt
```
